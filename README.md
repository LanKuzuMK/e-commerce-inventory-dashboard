# E-Commerce Inventory Dashboard

This project is a dynamic web application containing an inventory dashboard built using JSP, Expression Language (EL 3.0+), and JSTL 3.0.

## Login Credentials

You can log in to the dashboard using any of the following accounts:

- **Username:** `admin` | **Password:** `111`
- **Username:** `user`  | **Password:** `222`
- **Username:** `guest` | **Password:** `333`

## Requirements
- Java 17 or higher
- Apache Tomcat 11
- JSTL 3.0 API and Implementation (included in `src/main/webapp/WEB-INF/lib`)

## Setup
To run this locally, target a Tomcat 11 runtime environment and deploy the `src/main/webapp` folder as the root context.
